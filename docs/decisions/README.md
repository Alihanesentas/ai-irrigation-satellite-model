# Decision Records

One decision per file, named by topic. Format: Status / Context / Decision / Rationale /
Consequences / Rejected alternatives.

See `index.md` for the current table — this file had drifted out of sync with it (missing
several records) before this note was added; `index.md` is the one kept up to date.

**Status meanings**
- **Accepted** — explicitly approved, binding
- **Proposed** — analysed and recommended, not explicitly approved. Confirm before implementing.
- **Superseded** — replaced; retained for rationale. See `../superseded-decisions.md`.
- Unsettled questions live in `../open-decisions.md`
